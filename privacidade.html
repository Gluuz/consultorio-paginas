Política de privacidade

Agenda do Consultório. Atualizada em 3 de outubro de 2026.

A Agenda do Consultório é um sistema instalado no computador de um consultório de psicologia e usado só pela psicóloga responsável. Esta política explica como ele usa os dados da conta Google que ela conecta.

Dados do Google que o sistema acessa

  • Lista de agendas: para saber quais agendas ler.
  • Eventos das agendas: data, horário e título. O título é lido só para verificar se contém a palavra de bloqueio combinada e não é guardado.
  • Agenda "Consultório": o sistema cria essa agenda e, nela, cria, altera e apaga os eventos das sessões, com o nome do paciente, o horário e o link da videochamada. Ele não altera nenhuma outra agenda.
  • Endereço da conta: para mostrar no painel qual conta está conectada.

Como os dados são usados e guardados

  • Dos eventos com a palavra de bloqueio, o sistema guarda só o início e o fim, para não oferecer esses horários aos pacientes.
  • A autorização de acesso ao Google fica guardada de forma criptografada.
  • Tudo fica no banco de dados do computador do consultório. Não há servidor do sistema na internet.

Compartilhamento

Os dados obtidos do Google não são vendidos, compartilhados com terceiros, usados para publicidade nem usados para treinar modelos de inteligência artificial. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

  • No painel do sistema, o botão de desconectar o Google Agenda revoga o acesso e apaga a autorização e os bloqueios guardados.
  • O acesso também pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Contato

Dúvidas sobre esta política podem ser enviadas ao e-mail de suporte que aparece na tela de autorização do Google.
